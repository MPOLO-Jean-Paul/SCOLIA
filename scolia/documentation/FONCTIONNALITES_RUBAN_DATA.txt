ITM CD — RUBAN DE COMMANDES ET DOSSIER DATA
Édition du 7 octobre 2026 — passerelle ITM-DESKTOP-4

MISE À JOUR
1. Fermez Excel et l'ancienne application. Décompressez ce ZIP entièrement.
2. Ouvrez INSTALLER.vbs, l'installateur graphique direct, sans fenêtre cmd.
   Choisissez VOTRE CLASSEUR ACTUEL contenant les derniers enregistrements.
   Ne reprenez pas FICHIER_SOURCE.xlsm pour remplacer vos données récentes.
   L'installateur conserve l'original et prépare une nouvelle copie corrigée.
3. Ouvrez APPLICATION.vbs et connectez cette nouvelle copie corrigée.
   Elle est importée une fois dans data. L'original reste conservé.
4. Les prochaines ouvertures retrouvent le dossier data mémorisé automatiquement.
   Reconnecter le même fichier d'import retrouve les données déjà gérées.

RUBAN PAR ONGLET
Tableau de bord : Classeur ; Saisie ; Analyse.
Apprenants : Classeur ; Dossiers ; Recherche ; Listes.
Paiements : Classeur ; Caisse ; Historique.
Exports : Classeur ; Rapports ; Contrôle.
Diagnostic : Classeur ; Qualité des données.
Administration : Classeur ; Données ; Paramètres.
Sécurité : Classeur ; Accès ; Préférences.
Chaque groupe rassemble les commandes correspondantes. Sur un petit écran,
le ruban défile horizontalement. Les actions nécessitant des données ou une
année ouverte sont désactivées quand leur condition n'est pas satisfaite.
Les commandes du ruban utilisent les mêmes traitements que les boutons des
pages. Les listes visibles peuvent être exportées en CSV avec leurs filtres.
Le contrôle avant export utilise le même moteur et les mêmes filtres que le
rapport final. La protection et la page de connexion sont conservées.

CLASSEURS ET DONNÉES
Administration > Classeurs et données affiche le classeur actif, les fichiers
historiques, leurs nombres de lignes et leurs tailles. On peut ouvrir le
dossier, contrôler les structures, régler les seuils ou créer le suivant.

Par défaut : 10 000 apprenants OU 50 000 lignes de paiement par classeur.
Une opération de paiement peut créer jusqu'à neuf lignes : la place est
réservée avant son enregistrement. Quand le seuil nécessaire est dépassé,
le logiciel crée le fichier suivant et bascule sans intervention.
Chaque nouveau tableau conserve ses titres en ligne 4 et ses données en
ligne 5. Aucun fichier historique n'est effacé lors du basculement.
Les seuils sont des limites pratiques réglables, inférieures à la limite
physique d'Excel. Ils ne dépendent pas des cellules seulement mises en forme.

Un dossier data contient :
- un sous-dossier identifié pour chaque base/année importée ;
- registre.json : liste complète des segments, fichier actif et seuils ;
- classeur-000001.xlsm, classeur-000002.xlsm, etc. ;
- sauvegardes : copies complètes et empreintes SHA-256 ;
- transaction-... : copies de protection pour les opérations sur plusieurs
  fichiers ; transaction.json existe uniquement pendant une telle opération ;
- temp : copies de travail pour les corrections et la clôture annuelle.

Les recherches, soldes, contrôles de doublons et rapports lisent tous les
classeurs enregistrés de la même base. Les matricules, numéros de reçus et
nouveaux IDs de paiements sont recherchés à travers tous les segments.
Une modification de dossier rejoint le classeur où réside son inscription.
La correction d'un reçu recalcule l'ensemble de l'historique de cet apprenant,
y compris les versements d'autres segments, et conserve un journal.
Les frais sont synchronisés ; les restrictions liées aux paiements existants
s'appliquent à tous les fichiers, y compris les anciens segments.
Un segment manquant bloque les calculs : aucun rapport partiel n'est accepté.

SAUVEGARDES, RÉCUPÉRATION ET ANNÉES
Créer une sauvegarde couvre toute la base data, et non uniquement le fichier
actif. Restaurer copie vérifie les empreintes, crée un nouveau dossier et le
connecte. La base actuelle est conservée.
Un journal de récupération permet d'annuler au prochain démarrage une
opération sur plusieurs fichiers qui aurait été interrompue. Les copies
sont toutes vérifiées avant restauration. Aucun nettoyage automatique des
archives ou sauvegardes n'est appliqué dans cette édition.
La clôture reste une action volontaire. Elle sauvegarde la base complète,
consolide les dossiers pour la nouvelle année et clôture les anciens segments.
Le basculement de capacité conserve l'année et les soldes : ce n'est pas une
clôture annuelle et il ne remet pas les paiements à zéro.

UTILISATION
Travaillez depuis APPLICATION.vbs. Un classeur data isolé n'est pas une base
complète et ne peut pas être importé comme tel. Pour déplacer ou sauvegarder
le logiciel, conservez le dossier data entier. Ne supprimez pas ses fichiers.
Le verrou de session évite deux applications écrivant simultanément dans
la même base. Fermez Excel avant de connecter ou de restaurer les données.
Après la première importation, les nouvelles saisies résident dans data,
pas dans l'ancien classeur choisi pour l'import.
Les anciens classeurs DESKTOP-2/3 restent consultables en mode fichier unique ;
préparez cette édition pour activer la gestion data.

CONTRÔLES ET LIMITES
L'installateur exécute sous Windows/Excel un test sur deux copies temporaires :
lecture commune, solde cumulé, paiement d'un apprenant d'un autre classeur,
unicité du matricule, effectif global exportable et refus d'un segment absent.
Un second test natif vérifie le passage du 100e au 101e dossier, la correction
d'un reçu sur plusieurs segments, le basculement des paiements, l'annulation
d'une transaction, puis la sauvegarde, restauration et réouverture de la base.
Il conserve aussi les contrôles d'exports à grand volume de l'édition précédente.
Ces tests natifs seront exécutés sur votre PC pendant la préparation : cet
environnement de développement ne dispose pas de Windows ni d'Excel COM.
La préparation du ZIP a fait l'objet de contrôles statiques ; elle ne constitue
pas une validation de tous les clics ou des performances sur votre machine.

Les segments restent ouverts dans Excel en arrière-plan pendant la session ;
la capacité pratique dépend donc de la mémoire et de la version d'Excel.
La clôture annuelle consolide dans une feuille : elle s'interrompt sans modifier
la base si une consolidation dépasserait la capacité physique d'Excel.
Le format existant de matricule à six caractères reste conservé, avec l'espace
de codes prévu par promotion. Le logiciel signale son épuisement explicitement.
Les sauvegardes occupent progressivement du disque : surveillez l'espace libre.
