# SCOLIA Pro 1.2.78 — Écoles, universités, bulletins officiels et audit de qualité

## Nouveautés
- Choix du type d'établissement : ITM/IM (inchangé), maternelle, primaire, secondaire et technique,
  complexe scolaire, université LMD.
- EPST : règlement pédagogique par année ; maxima par branche ; périodes, examens et totaux par trimestre
  (primaire) ou semestre (secondaire) ; application et conduite ; délibération, repêchage, palmarès ;
  examens nationaux ; réinscription selon la décision.
- Bulletin EPST sur le modèle national de la RDC, identique sur ordinateur et sur téléphone serveur.
  Il porte la province, la commune, le code de l'école et le N° permanent de l'élève.
- Université LMD : filières, maquette UE/EC, frais en USD par tranches ; résultats partiels du S1 ;
  première session sur tous les cours de la promotion ; deuxième session, dettes académiques ;
  relevés et procès-verbaux.
- Saisie des notes par les enseignants (branches EPST, EC LMD) ; comptes étudiants pour consulter les
  résultats publiés.

## Corrections (audit de qualité)
- Trois pannes du serveur corrigées : convocation introuvable, sauvegarde en ligne sans inscription,
  console injoignable.
- Écrans adaptés à chaque profil : attribution des branches ou des EC, privilège jury réservé aux ITM/IM,
  vocabulaire élève/étudiant, interface web.
- Réactivation d'un compte enseignant ; boutons des délibérations selon l'étape.
- Bannière d'un autre poste en bas à droite sur ordinateur ; textes indicatifs (Avalonia 12) ; rang
  libellé sur les cartes du téléphone ; organisation LMD en français.
- Détail : `docs/AUDIT_QUALITE_20261114.md` et `docs/EPST_UNIVERSITE_ETAT_ET_UTILISATION.md`.
