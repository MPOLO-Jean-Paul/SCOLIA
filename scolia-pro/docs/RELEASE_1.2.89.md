# SCOLIA Pro 1.2.89 — Codes non attribués et sauvegardes plus lisibles

## Codes anonymes et documents
- Quand aucun code anonyme actif n'est attribué, les libellés associant le code et le nom affichent le nom seul, sans réutiliser un matricule technique ni celui d'une ancienne année scolaire.
- Les rubriques matricule des reçus, relevés, bulletins et bulletins de cycle restent vides tant que le code n'est pas disponible, comme sur les cartes d'accès.
- Les références internes nécessaires à la connexion et à la traçabilité ne sont pas effacées.

## Sauvegardes, interface Windows et Android
- L'écran Données > Sauvegardes distingue les copies récentes (moins de 26 heures) et les sauvegardes à refaire.
- Chaque copie présente clairement son type, sa date, son ancienneté et sa taille. Son nom de fichier reste consultable.
- Harmonisation des libellés dans la caisse, les reçus récents, le rapport du jour et les résultats scolaires, notamment sur téléphone.

## Contrôles de publication
- Tests de navigation adaptés au code anonyme non encore attribué.
- La base SQLite locale, les droits des établissements, la signature Android et la configuration Cloudflare ne sont pas migrés par cette version.

## Avant installation
Synchroniser les appareils, conserver une sauvegarde vérifiée et ne pas effectuer la mise à niveau pendant un encaissement. Installer une APK portant le certificat officiel de la version déjà en place ; ne jamais désinstaller l'application pour contourner un avertissement de signature.
