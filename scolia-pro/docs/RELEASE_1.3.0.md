# SCOLIA Pro 1.3.0 — Android et Windows

- Android : évolution progressive vers Flutter Material 3, thèmes clair et sombre, navigation et formulaires adaptés au téléphone.
- Conservation du moteur métier natif .NET, des droits, du stockage SQLite et du modèle existant des cartes d'accès ; les écrans non migrés restent accessibles via l'interface native.
- Mise à niveau testée sur émulateur isolé : conservation du cache chiffré, compte hors connexion, opération en attente et point de reprise de synchronisation.
- Windows : interface native conservée.
- Mise à jour Android : identifiant historique, comparaison obligatoire du certificat et des versions avec la dernière release officielle. Une sauvegarde vérifiée est recommandée avant la première installation.
- Diffusion conditionnée à la vérification du candidat ARM signé sur appareil de test ; ne jamais utiliser le paquet expérimental avec les données réelles.
